# Builder Automation

This project contains a BDD automated test suite for validating accessibility and usability criteria in courses generated by Builder.

## Overview

The automation uses:
- Cucumber for writing scenarios in natural language
- Playwright for browser-based test execution
- Axe for detecting common accessibility issues
- HTML reports generated automatically for result analysis

## Covered functionality

The project includes scenarios to validate:
- Course interface accessibility
- Semantic structure of tags and elements
- Alt attributes on images
- Heading hierarchy
- Link names and descriptions
- Keyboard navigation
- ARIA usage and accessible names
- Usability and visual feedback for accessibility features

## Project structure

- features/: .feature files with the BDD scenarios
- features/support/steps/: Cucumber step definitions
- features/support/pages/: Page Object classes that encapsulate UI interactions
- reports/: HTML reports generated during execution

## Prerequisites

Before running the tests, make sure you have installed:
- Node.js 18 or later
- npm

## Installation

From the project root, run:

```bash
npm install
```

## Running the tests

### Run the full suite

```bash
npm run test:bdd
```

### Run in CI mode

```bash
npm run test:ci
```

## Reports

Accessibility HTML reports are saved in the reports/ folder.

Examples:
- reports/acessibilidade-Curso1.html
- reports/acessibilidade-Curso2.html

## Notes

The tests run against Builder's quality environment and depend on the URLs and credentials configured in the automation steps. If the environment changes, these values may need to be adjusted in the support files.
